# Τροχιές: site

Στατικό site φτιαγμένο με [Astro](https://astro.build). Δεν έχει βάση δεδομένων ούτε admin: όλο το περιεχόμενο είναι απλά αρχεία κειμένου.

## Πρώτη φορά

Χρειάζεσαι [Node.js](https://nodejs.org) (έκδοση 22 ή νεότερη).

```bash
npm install      # μία φορά
npm run dev      # ανοίγει το site στο http://localhost:4321 και ανανεώνεται μόλις αλλάξεις κάτι
npm run build    # φτιάχνει το τελικό site στον φάκελο dist/ (αυτό ανεβαίνει σε hosting)
```

## Τι αλλάζω και πού

| Θέλω να αλλάξω… | Αρχείο |
|---|---|
| Email, socials, μενού, χρονολόγιο | `src/site.config.ts` |
| Μια παράσταση (κείμενο, ταυτότητα, ημερομηνίες, κριτικές) | `src/content/parastaseis/<όνομα>.md` |
| Νέα παράσταση | Αντέγραψε ένα `.md`, άλλαξε όνομα αρχείου και περιεχόμενο. Το όνομα αρχείου γίνεται το URL. |
| Μέλη της ομάδας | `src/data/meli.yaml` |
| **Accent χρώμα**, χρώματα, γραμματοσειρές, αποστάσεις | `src/styles/tokens.css` (η γραμμή `--accent`) |
| Κείμενα της αρχικής / ομάδας / επικοινωνίας | `src/pages/index.astro`, `omada.astro`, `epikoinonia.astro` |

### Φωτογραφίες
1. Βάλε τις εικόνες στο `public/images/`.
2. Στο `.md` της παράστασης γράψε `cover: /images/onoma.jpg` και/ή
   ```yaml
   gallery:
     - /images/foto1.jpg
     - /images/foto2.jpg
   ```
   Όπου δεν υπάρχει φωτογραφία, εμφανίζεται αυτόματα ένα γεωμετρικό placeholder. Οι φωτογραφίες εμφανίζονται ασπρόμαυρες (μπορείς να το αλλάξεις στο `src/components/Media.astro`).

### Ημερομηνίες παραστάσεων
```yaml
dates:
  - { city: Αθήνα, venue: "Θέατρο Χώρος", from: 2026-10-17, to: 2026-10-25, note: "21:15", tickets: "https://..." }
```
Ό,τι έχει περάσει γκριζάρει αυτόματα. Αν υπάρχουν μελλοντικές ημερομηνίες, η αρχική γράφει «Επόμενες παραστάσεις».
⚠️ Αν μια τιμή έχει κόμμα, βάλ' την σε εισαγωγικά.

## Πώς είναι φτιαγμένο

- `src/components/Orbits.astro` και `src/scripts/orbits.ts`: το κινούμενο σύστημα τροχιών (αρχική, ομάδα, επικοινωνία, 404).
- `src/layouts/Base.astro`: κοινό πλαίσιο κάθε σελίδας και η μετάβαση που «ανοίγει» την επόμενη σελίδα σαν έλλειψη από το σημείο του κλικ.
- `src/components/ShowList.astro`: η λίστα παραστάσεων με τον ελλειπτικό φακό στο hover.
- `src/components/RingLink.astro`: σύνδεσμοι με έλλειψη που ζωγραφίζεται γύρω τους.
- `src/components/OrbitPattern.astro`: το μοτίβο τροχιών των placeholders και του footer.
- Γραμματοσειρές: Commissioner (του Έλληνα σχεδιαστή Κώστα Μπαρτσόκα) και GFS Didot, και οι δύο φιλοξενούνται τοπικά.

## Εκκρεμότητες (⚠️ μέσα στα αρχεία)
- Πραγματικό email στο `src/site.config.ts`.
- Στοιχεία για «Σκουπίδια», «Αφηγήτρια Ταινιών», «Κλημεντίνες χωρίς κουκούτσι».
- Ακριβείς ημερομηνίες για το Θέατρο Ροές («Εκτελούνται Έργα»).
- Επιβεβαίωση της λίστας μελών.
- Φωτογραφίες και λογότυπο.
- Domain στο `astro.config.mjs` όταν βγει online.
